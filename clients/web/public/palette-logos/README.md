# Logotipos por ave/paleta

Sube aquí el logotipo que corresponda a cada paleta, ya sea YomDental o YomCeph. Conserva el fondo transparente cuando el diseño lo requiera y utiliza nombres que identifiquen marca y ave.

Ejemplos:
- yomdental_agapornis.png
- yomceph_agapornis.png
- yomdental_tucan.png
- yomceph_tucan.png

Repite el patrón para pavo_real, ninfa, faisan, quetzal, guacamaya_roja, guacamayo_azul, buho y colibri. Se aceptan PNG o SVG. No reemplaces los logotipos generales existentes de AVIS.
