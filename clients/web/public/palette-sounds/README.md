# Sonidos de aves por paleta

Sube aquí un archivo de audio por cada ave/paleta. Usa nombres consistentes y en minúsculas:

- agapornis.mp3
- tucan.mp3
- pavo_real.mp3
- ninfa.mp3
- faisan.mp3
- quetzal.mp3
- guacamaya_roja.mp3
- guacamayo_azul.mp3
- buho.mp3
- colibri.mp3

Formatos recomendados: MP3 u OGG. Evita espacios y acentos en los nombres. Esta carpeta es para los sonidos, no para imágenes.
