# Pack Análisis Dentales

Aplicación de escritorio para Windows orientada a expedientes odontológicos, captura de estudios y análisis ortodóncicos.

El repositorio inicia como base limpia. El desarrollo funcional se realizará en `develop/desktop-foundation`; `main` conservará la referencia inicial hasta que la aplicación tenga pruebas y empaquetado.

## Alcance inicial

- Expedientes de pacientes con registros históricos.
- Carga o captura de radiografías, fotografías clínicas y modelos de estudio.
- Conservación del archivo original y procesamiento sobre copias derivadas.
- Catálogo de análisis vinculado al tipo de estudio.
- Registro profesional de mediciones, observaciones y conclusiones.
- Reporte PDF integrado en una fase posterior.

## Estado

En construcción. Las mediciones e interpretaciones deben ser revisadas y validadas por el profesional responsable; la aplicación no sustituye el diagnóstico clínico.
