# Identidad visual AVIS — Colibrí

La mascota oficial de AVIS es un colibrí. No utilizar agapornis ni búhos en los recursos nuevos.

- Nombre: AVIS
- Descriptor: Análisis Odontológico Integral
- Slogan: Observa • Analiza • Integra
- Paleta: morado #6D45A6, ciruela #48263F, turquesa #22B8B0, menta #C8F0E2, blanco #FFFFFF y gris #E9E9EE.
- Recursos web SVG con fondo transparente: `public/avis-icon.svg`, `public/avis-colibri.svg`, `public/avis-logo.svg` y `public/avis-slogan.svg`.
